### 🚀 Featured Highlights & Production Work

#### 🛡️ [Flag-Forge — Cybersecurity CTF Platform](https://www.flagforgectf.com)
* **Architecture:** Full-stack competitive cybersecurity CTF platform supporting streak tracking, point calculation algorithms, challenge verification, and dynamic leaderboards.
* **Tech Stack:** `TypeScript` • `React.js` • `Node.js` • `Express.js` • `MongoDB` • `Redis`
* **Links:** [Live Site ↗](https://www.flagforgectf.com) • [Backend Repository ↗](https://github.com/Samhubby/flagforge-backend)

#### 🏦 Banking BPM & Workflow Automation Portal (Enterprise Experience)
* **Architecture:** Engineered Business Process Management (BPM) dashboards and secure customer portals for commercial banks using Laravel. Implemented asynchronous event-driven integrations with **RabbitMQ** to handle high-reliability cross-system messaging and automated case handling.
* **Tech Stack:** `Laravel` • `RabbitMQ` • `MySQL` • `Docker` • `Jenkins CI/CD`
* **Impact:** Reduced processing friction, monitored live banking workflow states, and ensured decoupled asynchronous communication across microservices.

#### 🐳 [Learntern — Multi-Tier Containerized Platform](https://github.com/Samhubby/Learntern)
* **Architecture:** Containerized full-stack application separating Laravel REST API, Next.js client, and MySQL persistence layer behind an Nginx reverse proxy using Docker Compose.
* **Tech Stack:** `PHP / Laravel` • `Next.js` • `Nginx` • `MySQL` • `Docker Compose`
* **Links:** [Repository ↗](https://github.com/Samhubby/Learntern)
